# WordNest 🌍
WordNest is an AI-powered language learning assistant built using LangGraph, Groq LLMs, and Streamlit.
The application helps users learn vocabulary interactively by generating:

* Vocabulary words
* Word translations
* Example sentences
* Short practice paragraphs/texts

Users can select:

* the language they want to learn
* their base/native language
* difficulty level
* number of words

The app then generates personalized learning content using LLMs.

⸻

## Features

✅ Multi-language vocabulary generation

✅ Difficulty-based word selection

* Beginner
* Intermediate
* Advanced

✅ AI-generated translations

✅ AI-generated example sentences

✅ AI-generated short practice texts

✅ Interactive Streamlit UI
